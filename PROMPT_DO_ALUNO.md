# Prompt do aluno

Depois que o repositório estiver público, mande ao Hermes do aluno:

```text
Vamos seguir este processo: https://github.com/SEU_USUARIO/assistente-financeiro-hermes
```

Se o Hermes não abrir links automaticamente, mande:

```text
Abra este repositório, leia o START_HERE.md e siga o processo de ponta a ponta: https://github.com/SEU_USUARIO/assistente-financeiro-hermes
```
